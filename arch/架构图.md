# 架构图（组件调用关系）

> 用符号拼出的游戏组件调用关系图。约定见 [[架构总览]]、事件清单见 [[代码与命名规范]]、接口见 [[功能总览]]。
> 图例：`→` 直接调用 · `⇒` 事件广播（EventCenter）· `- -►` 物理碰撞检测。

## 1. 分层总览

```
┌─────────────────────────────────────────────────────────────────────┐
│ 场景层：MainMenu(选关/设置/团队介绍)  │  Level_01~03(地图+组件+玩家+HUD) │
└───────────────┬───────────────────┴──────────────────┬──────────────┘
                │ 主动方：直接调用                       │ 被动组件：事件广播
                ▼                                      ▼
        ┌───────────────┐                     ┌──────────────────┐
        │   UI / 玩家    │                     │  EventCenter (A) │
        │  (C / D)      │                     │  订阅/退订/广播    │
        └───────┬───────┘                     └────────┬─────────┘
                │ 直接调用                              │ 订阅
                ▼                                      ▼
        ┌────────────────────────────────────────────────────────┐
        │                    GameManager (A)                     │
        │  关卡状态机 / 关卡流 / 暂停 / 计时 / 死亡计数 / 重生        │
        └──┬──────────┬──────────┬──────────┬──────────┬─────────┘
           ▼          ▼          ▼          ▼          ▼
     ProgressMgr  UIManager  AudioMgr  SceneManager  PlayerController
        (B)         (C)        (B)      LoadScene       (D)
```

## 2. 被动组件 → GameManager（事件广播，组件只通知）

```
尖刺   Spike       ──⇒ PlayerDeath ──────────┐
存档点 SavePoint   ──⇒ SavePointReached ─────┤
终点   Goal        ──⇒ LevelComplete ────────┤
                                              ▼
                                       EventCenter (A)
                                              │ 订阅
                                              ▼
                                       GameManager (A) 决策
```

## 3. GameManager → 其他（广播 + 调用）

```
GameManager (A)
  ├─ ⇒ DeathCountChanged ──► HUD (C)          刷新死亡次数
  ├─ ⇒ TimerTick ──────────► HUD (C)          刷新计时
  ├─ ⇒ PlayerRespawned ────► 尖刺/按钮/门/移动平台  复位
  ├─ ⇒ Pause / Resume ─────► 各需响应对象
  ├─ → ProgressManager (B)  IsLevelUnlocked / UnlockLevel / TotalLevels
  ├─ → UIManager (C)        ShowPauseMenu / ShowClearHint / ShowCompleteUI
  ├─ → AudioManager (B)     PlayBGM / PlaySFX
  └─ → SceneManager         LoadScene("Level_0N" / "MainMenu")
```

## 4. 主动方 → GameManager（直接调用）

```
选关/暂停 UI (C)  → GameManager.LoadLevel / RestartLevel / ResumeGame / PauseGame / BackToMainMenu
设置页 UI (C)     → ProgressManager(B).MusicVolume / SFXVolume / BgmIndex
设置页 UI (C)     → AudioManager(B).PlayBGM            (切换即试听)
玩家 (D) Start    → GameManager.RegisterPlayer(自身引用 + 出生点位置)
玩家 (D) 动画事件 → PlayerController.OnDeathAnimationFinished → GameManager.OnPlayerDeathAnimationFinished
```

## 5. 子弹 / 按钮 / 机关（关卡局部，F，不经过全局）

```
玩家按 J ──► PlayerController (D) 实例化 Bullet (D)
   Bullet - -直线飞行- -► ButtonTarget (F)  OnTriggerEnter2D 检测
   ButtonTarget (F) ──► Door.Open() / MovingPlatform.StartMove()  (Inspector 直接引用)
   ButtonTarget (F) ──► Destroy(Bullet)
```

> 注意：子弹是"哑弹"，**不检测按钮**；按钮检测子弹。子弹撞墙（`Ground` 层）或超时自行销毁。

## 6. 关键链路时序

**① 死亡 → 重生**
```
尖刺碰玩家
  → Spike ⇒ PlayerDeath
  → GameManager：死亡次数+1 ⇒ DeathCountChanged（HUD 刷新）
  → GameManager → Player.Die() 播死亡动画
  → 动画事件 → PlayerController.OnDeathAnimationFinished → GameManager
  → GameManager → Player.Respawn(出生点/存档点) ⇒ PlayerRespawned
  → 尖刺/按钮/门 ⇒ 复位
```

**② 通关 → 下一关**
```
玩家到终点
  → Goal ⇒ LevelComplete
  → GameManager → ProgressManager.UnlockLevel(下一关)（写 JSON）
  → 非最后一关：UIManager.ShowClearHint → 1.5s → SceneManager.LoadScene(下一关)
  → 最后一关：UIManager.ShowCompleteUI → 返回主菜单
```

**③ 选关**
```
选关 UI 点"第 N 关"
  → GameManager.LoadLevel(N)
  → ProgressManager.IsLevelUnlocked(N)（校验）
  → 恢复 timeScale + 重置计时/死亡/存档点
  → SceneManager.LoadScene("Level_0N")
```

**④ 按钮开机关**
```
玩家按 J → Bullet 直线飞 → ButtonTarget 检测到子弹 → 关卡逻辑 + 子弹销毁
```

**⑤ 设置音量**
```
拖动滑动条 → 只改内存变量(实时预览)
松手 → ProgressManager.MusicVolume = v（写 JSON）→ AudioManager.SetMusicVolume(v)
```
