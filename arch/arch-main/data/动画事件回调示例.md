# 动画事件回调示例（Animation Event）

> 讲解 Unity **Animation Event（动画事件）**：在动画的某一帧自动回调一个函数。本项目用于"死亡动画播完 → 通知 GameManager 重生"。从 [[玩法系统规范]] 第 1 节跳转而来。

## 1. 什么是 Animation Event

动画 Clip 播放到某一帧时，自动调用一个**挂在同一 GameObject 上的组件**的 public 方法。

**关键限制**：Animation Event 只能调用"**同一物体上组件**"的方法，不能直接调到别的物体（如 Bootstrap 上的 GameManager）。

## 2. 本项目的用法（死亡重生）

死亡动画最后一帧 → 回调玩家身上的 `PlayerController.OnDeathAnimationFinished()` → 它再调用 `GameManager.Instance`。

## 3. 配置步骤

1. 在 Project 窗口选中玩家的**死亡动画 Clip**。
2. 打开 Animation 窗口（`Window > Animation > Animation`），确认预览的是该 Clip。
3. 把时间线拖到最后一帧，点上方 **Add Event**（菱形图标）。
4. 在 Inspector 的 Event 面板里，`Function` 填 `OnDeathAnimationFinished`（参数留空）。
5. 确认玩家 GameObject 上挂了 `PlayerController`，且里面有这个 public 方法。

## 4. 代码示例

```csharp
// 玩家身上：这个方法被 Animation Event 回调
public void OnDeathAnimationFinished() {
    // 玩家是"主动方"，通过单例直连 GameManager
    GameManager.Instance.OnPlayerDeathAnimationFinished();
}
```

```csharp
// GameManager（Bootstrap 上）：真正执行重生
public void OnPlayerDeathAnimationFinished() {
    player.Respawn(lastSavePoint);                       // 移回出生点/存档点，恢复输入
    EventCenter.Broadcast(GameEvent.PlayerRespawned);    // 通知关卡机关重置
}
```

## 5. 常见坑

1. **函数名拼错/大小写不一致** → Event 不触发（Unity 会警告 no receiver）。
2. **方法不在同一物体上** → 收不到；解决：在玩家上放中转方法再调 GameManager。
3. **方法不是 public** → 收不到。
4. **动画被提前打断** → Event 不会触发（所以死亡动画期间要禁用输入、冻结控制）。
