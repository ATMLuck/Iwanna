# Physics2D 碰撞矩阵配置说明

> Unity 2D 的 **Layer Collision Matrix（层碰撞矩阵）**，并给出本项目的完整配置。层定义见 [[代码与命名规范]] 6.2。

## 1. 什么是碰撞矩阵

Unity 用一张"层 × 层"的表来决定**哪些层之间会发生碰撞/触发**。

- **勾选** = 这两层可以交互；
- **不勾** = 直接忽略（连回调都不产生），既省性能又避免误触发。

## 2. 配置入口

`Edit > Project Settings > Physics 2D > Layer Collision Matrix`（一张勾选表）。

## 3. 本项目 6 层

| Layer | 层名 | 挂载物体 |
|---|---|---|
| 8 | `Player` | Player |
| 9 | `Ground` | 地形 |
| 10 | `Damage` | Spike |
| 11 | `Bullet` | Bullet |
| 12 | `Button` | ButtonTarget |
| 13 | `Trigger` | SavePoint、Goal |

> 完整配置（Rigidbody2D / Collider2D / isTrigger）见 [[代码与命名规范]] 6.2。

## 4. 只勾选这 5 组层对

| 勾选 | 交互类型 | 说明 |
|---|---|---|
| Player ↔ Ground | 碰撞 | 玩家站立 |
| Player ↔ Damage | 触发 | 尖刺即死 |
| Player ↔ Trigger | 触发 | 存档点/终点 |
| Bullet ↔ Ground | 碰撞 | 子弹撞墙销毁 |
| Bullet ↔ Button | 触发 | 子弹命中按钮 |

其余层对**全部不勾**。

## 5. 原理（三个要点）

1. **勾选 = 可交互**；不勾 = 彻底忽略。
2. **碰撞 vs 触发**由碰撞体的 `isTrigger` 决定（不是矩阵决定的）。
3. **至少一方有 Rigidbody2D** 才会产生回调；静态触发体（尖刺/按钮/存档点）本身可不加 Rigidbody2D，靠"对方（玩家/子弹）有 Rigidbody2D"即可。

## 6. 常见坑

1. 忘了勾 → 尖刺/按钮不触发。
2. `isTrigger` 忘勾 → 尖刺变成"撞上去弹开"而不是穿透触发。
3. 代码里硬编码层号 → 改层后全坏；用 `LayerMask.NameToLayer("Player")`。
4. 两个都是静态碰撞体（都无 Rigidbody2D）→ 不产生回调。
