# 玩法系统规范

> 各玩法组件的职责与"只通知不决策"的边界。事件与命名见 [[代码与命名规范]]，整体见 [[架构总览]]。

## 0. 核心原则（对"组件只通知"的细化）

- **全局状态类事件**（死亡/存档/通关/计时）→ 组件 `Broadcast`，由 `GameManager` 订阅并决策。
- **关卡内局部机关联动**（按钮→开门/移动平台）→ 归**F:关卡设计人**独自负责：组件**直接持有目标机关引用**（Inspector 拖拽）并调用，**不产生全局事件、GameManager 不参与**，避免上帝类。
- **重生复位约定**：关卡内一次性机关（尖刺/按钮/门/移动平台）订阅 `PlayerRespawned`，重生后复位自身（`OnEnable` 订阅 / `OnDisable` 退订）。

## 1. 玩家控制器 `PlayerController`

- **移动**：`rb.velocity = new Vector2(Input.GetAxisRaw(InputDef.Horizontal) * moveSpeed, rb.velocity.y)`；水平翻转 `transform.localScale.x = facingDir`。
- **跳跃 + 二段跳**：`GroundCheck` 子物体 + `Physics2D.OverlapCircle` 判着地；`jumpCount` 计数（最多 2 次），落地重置；跳跃设 `rb.velocity.y = jumpForce`。
- **面朝向**：`facingDir`（1 / -1），供子弹发射方向使用。
- **发射子弹（J）**：按 `InputDef.Shoot` 实例化 `Bullet` Prefab，初速度沿 `facingDir`。
- **不做 coyote time / jump buffer**，二段跳足够。
- **出生点与注册**：`Start()` 里记录 `spawnPosition = transform.position`（出生点 = 玩家在场景中的初始摆放位置，由 F:关卡设计人摆放），并调用 `GameManager.Instance.RegisterPlayer(this)` 把自身引用与出生点上报给 GameManager。

### 1.1 死亡 / 重生接口（Animation Event 回调）

1. 尖刺发 `PlayerDeath` → `GameManager.OnPlayerDeath`：死亡次数 +1、广播 `DeathCountChanged`、调用 `playerController.Die()`（禁用输入、播死亡动画）。
2. 死亡动画**最后一帧放 Animation Event**，回调**同物体**上的 `PlayerController.OnDeathAnimationFinished()`（Animation Event 只能调同一 GameObject 上的组件）。
3. `OnDeathAnimationFinished()` 调用 `GameManager.Instance.OnPlayerDeathAnimationFinished()`。
4. GameManager 把玩家移回出生点/最近存档点、恢复输入，并广播 `PlayerRespawned`。

> Animation Event 配置步骤见 [[动画事件回调示例]]。

> 玩家是"主动方"，不属于"只通知"的被动组件，但状态变更（死亡等）仍交给 GameManager 决策。

## 2. 子弹 `Bullet`（J 键，E:组件脚本负责人）

- 由 `PlayerController` 按 J 实例化，朝 `facingDir` 直线飞行。
- `Rigidbody2D`：Dynamic、`gravityScale = 0`，`rb.velocity = facingDir * bulletSpeed`。
- **只负责飞行与自我销毁，不主动检测按钮**：
  - 撞墙销毁：`OnCollisionEnter2D`（与 `Ground` 层碰撞）→ `Destroy(gameObject)`。
  - 超时销毁：`lifetime`（如 1.5s）用 `Invoke`/协程兜底，防飞出地图。
- 子弹是**哑弹**：不认识按钮、不触发任何逻辑，命中判定完全交给按钮（见第 3 节）。

## 3. 按钮组件 `ButtonTarget`（关卡局部，F:关卡设计人）

- **由按钮检测子弹**：`OnTriggerEnter2D` 里用 `other.GetComponent<Bullet>()` 判空确认是子弹。
- 命中后：**触发一次**（`isTriggered` 标记）→ 调用 Inspector 拖入的目标机关（`Door.Open()` 等）→ **销毁子弹** `Destroy(other.gameObject)`。
- **只走关卡局部逻辑**：不广播全局事件、GameManager 不参与；按钮只与关卡内事件有关。
- **归属**：`ButtonTarget` 与机关（门/移动平台）脚本在 `Scripts/Level/`，由**F:关卡设计人**编写与连线。
- 通常**只触发一次**，或可配置重复触发。

> **检测方向约定**：子弹不检测按钮，按钮检测子弹——子弹（E:组件脚本负责人）和按钮（F:关卡设计人）完全解耦，互不知道对方内部实现。

## 4. 尖刺 `Spike`（即死）

- `OnTriggerEnter2D` 检测 Tag `Player` → `EventCenter.Broadcast(GameEvent.PlayerDeath)`。
- **一次性标记**：`isTriggered` 防止连续触发（玩家擦边进进出出）。
- **不自己处理重生/计数**，只通知 GameManager。
- **复位**：订阅 `PlayerRespawned`，重生后 `isTriggered = false`（`OnEnable` 订阅 / `OnDisable` 退订）。

## 5. 存档点 `SavePoint`

- 玩家触碰（`OnTriggerEnter2D` 检测 Tag `Player`）→ **若未激活**：
  - `Broadcast(GameEvent.SavePointReached, 自身位置)`；
  - **替换贴图**：`SpriteRenderer.sprite = activatedSprite`（未激活 → 已激活的视觉反馈）；
  - `isActivated = true`（**只能触发一次**，之后不再广播）。
- `GameManager` 记录 `lastSavePoint`（初始 = 玩家初始摆放位置）；死亡重生用 `lastSavePoint`。
- 存档点**不订阅 `PlayerRespawned`**（激活后保持，不因死亡复位）——这是它区别于尖刺/按钮的地方。

## 6. 终点 `Goal` / 通关 / 下一关

- **终点触发**：`OnTriggerEnter2D` 检测 Tag `Player` → `Broadcast(GameEvent.LevelComplete)`；带 `isTriggered` 防连发（避免重复加载下一关）。
- **GameManager 通关处理**：
  1. 解锁下一关：`ProgressManager.UnlockLevel(currentLevel + 1)`（写 JSON，见 [[配置与存档规范]]）。
  2. 判断是否最后一关（用 `ProgressManager.TotalLevels`）。
  3. 非最后一关 → `UIManager` 弹简短通关提示（"通关！"）→ 延迟 1.5s 自动 `SceneManager.LoadScene(下一关)`（协程用 `WaitForSecondsRealtime`，不受 `Time.timeScale` 影响）。
  4. 最后一关 → 显示通关 UI，用户点"返回主菜单"。
- 通关提示期间冻结玩家输入，防止继续移动。

## 7. 死亡流程 / 计时 / 死亡次数（GameManager 决策）

- **死亡流程**：`PlayerDeath` → 死亡次数 +1 → 广播 `DeathCountChanged` → 播死亡动画（Animation Event 回调）→ 重生到出生点/最近存档点 → 广播 `PlayerRespawned`。
- **重生位置**：`GameManager.lastSavePoint`，初始 = 玩家初始摆放位置（`PlayerController.Start` 里通过 `RegisterPlayer` 上报）；收到 `SavePointReached` 后更新为该存档点位置。
- **计时**：`GameManager.Update` 累计 `elapsedTime`（float 秒），每帧广播 `TimerTick(elapsedTime)`；HUD 订阅刷新，显示为**纯秒数**（如 `37s`）。暂停时 `Time.timeScale=0` 使 `Update` 停走，计时自然暂停；**死亡动画期间继续累计**。
- **死亡次数**：`GameManager.DeathCount`，HUD 订阅 `DeathCountChanged` 刷新。
