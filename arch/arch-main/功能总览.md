# 功能总览

> 列出所有管理层类的**功能、对外接口、调用方法与功能**，是 [[架构总览]] 的补充。
> 事件清单与参数约定见 [[代码与命名规范]]；广播/订阅用法见 [[事件中心与广播订阅示例]]；单例基类见 [[代码与命名规范]] 第 5 节。

## 0. 管理层总览表

| 类 | 类型 | 负责人 | 职责一句话 |
|---|---|---|---|
| `GameManager` | Singleton（挂 Bootstrap） | 核心逻辑 | 关卡状态机 + 总协调 |
| `EventCenter` | 静态类（不挂物体） | 核心逻辑 | 事件广播 / 订阅 |
| `AudioManager` | Singleton（挂 Bootstrap） | 音频 + 存档 | 音乐 / 音效播放与音量 |
| `ProgressManager` | Singleton（挂 Bootstrap） | 音频 + 存档 | `config.json` 进度 + 设置读写 |
| `UIManager` | Singleton（挂 Bootstrap） | UI | 游戏内叠加 UI 切换 |

## 1. GameManager（A:核心逻辑负责人）

**功能**：
- 关卡状态机：进行中 / 暂停 / 死亡 / 通关。
- 关卡流：加载关卡、下一关、重新挑战、返回主菜单。
- 暂停 / 恢复（冻结 `Time.timeScale`）。
- 计时（`elapsedTime`）与死亡次数（`deathCount`）统计。
- 死亡重生协调（`lastSavePoint`，初始 = 玩家初始摆放位置）。

**对外接口**：

| 接口 | 功能 | 谁调用 |
|---|---|---|
| `void LoadLevel(int n)` | 加载第 n 关：校验解锁 → 恢复 timeScale → 重置计时/死亡/存档点 → `SceneManager.LoadScene("Level_0n")` | 选关 UI |
| `void RegisterPlayer(PlayerController player)` | 记录玩家引用与出生点（`lastSavePoint = 玩家初始位置`），并重置计时/死亡次数 | `PlayerController.Start()` |
| `void RestartLevel()` | 重新挑战本关 | 暂停菜单 UI |
| `void ResumeGame()` | 继续游戏（恢复 timeScale、隐藏暂停） | 暂停菜单 UI |
| `void PauseGame()` | 暂停游戏（冻结 timeScale、显示暂停） | Esc / 暂停按钮 |
| `void BackToMainMenu()` | 返回主菜单（恢复 timeScale + 加载 MainMenu） | 暂停菜单 / 通关 UI |
| `void OnPlayerDeathAnimationFinished()` | 死亡动画播完回调，执行重生并广播 `PlayerRespawned` | `PlayerController`（Animation Event 中转） |
| `float ElapsedTime { get; }` | 本关累计时长（秒） | HUD（订阅 TimerTick 时由事件携带） |
| `int DeathCount { get; }` | 死亡次数 | HUD（订阅 DeathCountChanged 时由事件携带） |

**内部订阅事件**：`PlayerDeath`、`SavePointReached`、`LevelComplete`。
**内部广播事件**：`DeathCountChanged`、`TimerTick`、`Pause`、`Resume`、`PlayerRespawned`。

**调用示例**：
```csharp
// 选关界面点击"第 2 关"
GameManager.Instance.LoadLevel(2);

// 暂停菜单"继续"
GameManager.Instance.ResumeGame();
```

## 2. EventCenter（静态类，A:核心逻辑负责人维护）

**功能**：事件的**订阅 / 退订 / 广播**，是"组件只通知、Manager 决策"的通信中枢。

**对外接口**：

| 接口 | 功能 | 谁调用 |
|---|---|---|
| `static void Subscribe(GameEvent e, Action<object> handler)` | 订阅事件 | 常驻 Manager（`Awake`）/ 临时对象（`OnEnable`） |
| `static void Unsubscribe(GameEvent e, Action<object> handler)` | 退订事件 | 临时对象（`OnDisable`） |
| `static void Broadcast(GameEvent e, object arg = null)` | 广播事件（携带参数） | 组件 / Manager |

**事件清单**（`GameEvent` 枚举）：`PlayerDeath`、`PlayerRespawned`、`SavePointReached`、`LevelComplete`、`DeathCountChanged`、`TimerTick`、`Pause`、`Resume`。

**调用示例**：
```csharp
EventCenter.Subscribe(GameEvent.PlayerDeath, OnPlayerDeath);
EventCenter.Broadcast(GameEvent.PlayerDeath);            // 无参
EventCenter.Broadcast(GameEvent.SavePointReached, pos);  // arg = Vector3
```

## 3. AudioManager（B:音频+存档负责人）

**功能**：背景音乐 / 音效播放、音量调节、切换 BGM。
**数据**：`AudioClip[] bgmList`（Inspector 拖入 `Audio/BGM/` 下剪辑）。

**对外接口**：

| 接口                             | 功能                            | 谁调用            |
| ------------------------------ | ----------------------------- | -------------- |
| `void PlayBGM(int index)`      | 切换并播放背景音乐（越界 clamp/取模）        | 设置页 UI（选歌）、进关卡 |
| `void SetMusicVolume(float v)` | 调背景音乐音量（`AudioSource.volume`） | 设置页 UI（滑动条松手）  |
| `void SetSFXVolume(float v)`   | 调音效音量                         | 设置页 UI（滑动条松手）  |
| `void PlaySFX(SFXType)`        | 播一次性音效（尖刺死亡、子弹发射等）            | 各组件            |
**添加SFXType枚举**：(暂定)
```C#
public enum SFXType

{
    PlayerDeath,      // 玩家死亡
    Shoot,            // 发射子弹
    Jump              // 跳跃
}
/*
PlaySFX(SFXType)直接传入枚举类型，由AudioManager内部处理音效映射
*/
```
**依赖**：从 `ProgressManager` 读 `BgmIndex` / `MusicVolume` / `SFXVolume`。

**调用示例**：
```csharp
AudioManager.Instance.PlayBGM(1);
AudioManager.Instance.SetMusicVolume(0.6f);
AudioManager.Instance.PlaySFX(PlayerDeath);
```

## 4. ProgressManager（B:音频+存档负责人）

**功能**：**全权接管** `config.json` 的读写（关卡进度 + 设置项）；其他组件读写存档必须经由它。

**对外接口**：

| 接口                                | 功能                         | 谁调用                         |
| --------------------------------- | -------------------------- | --------------------------- |
| `void Load()`                     | 读 JSON到内存                  | `Bootstrap` / `GameManager` |
| `bool IsLevelUnlocked(int level)` | 某关是否解锁                     | `GameManager`（选关 / 通关校验）    |
| `void UnlockLevel(int level)`     | 解锁某关（内部自动 `Save()`）        | `GameManager`（通关时）          |
| `int TotalLevels { get; }`        | 关卡总数（读自 JSON，= 3）          | `GameManager`               |
| `float MusicVolume { get; set; }` | 背景音乐音量（set 内部 `Save()`）    | `AudioManager` / 设置页        |
| `float SFXVolume { get; set; }`   | 音效音量（set 内部 `Save()`）      | `AudioManager` / 设置页        |
| `int BgmIndex { get; set; }`      | 当前 BGM 序号（set 内部 `Save()`） | 设置页 / `AudioManager`        |
| （private）`void Save()`            | 写 JSON                     | 仅内部                         |

**数据类**：`ProgressData`（`totalLevels` / `unlockedLevels` / `musicVolume` / `sfxVolume` / `bgmIndex`）。

**调用示例**：
```csharp
ProgressManager.Instance.Load();
if (ProgressManager.Instance.IsLevelUnlocked(2)) { ... }
ProgressManager.Instance.UnlockLevel(3);
ProgressManager.Instance.MusicVolume = 0.5f;   // setter 内部自动写盘
```

## 5. UIManager（C:UI负责人）

**功能**：游戏内**叠加 UI** 的显示 / 隐藏（HUD、暂停面板、通关提示、通关 UI）。

> **定位说明**：`UIManager` 常驻，负责游戏内叠加 UI；**主菜单场景内的界面**（主界面/选关/设置/团队介绍）由 `MainMenu` 场景内 UI 脚本负责，其中"选关/返回"动作调用 `GameManager` 完成场景切换。HUD 也常由关卡场景内的 HUD 对象订阅 `DeathCountChanged` / `TimerTick` 刷新（见 [[事件中心与广播订阅示例]]）。

**对外接口**：

| 接口                             | 功能                     | 谁调用                        |
| ------------------------------ | ---------------------- | -------------------------- |
| `void ShowHUD()` / `HideHUD()` | 显示 / 隐藏右上角 HUD         | `GameManager`（进关卡 / 暂停）    |
| `void ShowPauseMenu()`         | 显示暂停面板                 | `GameManager.PauseGame()`  |
| `void HidePauseMenu()`         | 隐藏暂停面板                 | `GameManager.ResumeGame()` |
| `void ShowClearHint()`         | 显示"通关！"简短提示            | `GameManager`（非最后一关通关）     |
| `void ShowCompleteUI()`        | 显示通关 UI（最后一关，含返回主菜单按钮） | `GameManager`（最后一关通关）      |


**调用示例**：
```csharp
UIManager.Instance.ShowPauseMenu();
UIManager.Instance.ShowClearHint();
```

## 6. Singleton<T> 基类 + Bootstrap（初始化）

**`Singleton<T>`**（基类，见 [[代码与命名规范]] 第 5 节）：`Awake` 防重复 + `DontDestroyOnLoad`，供各 Manager 继承。

**`Bootstrap`**：`MainMenu` 场景里的空物体，挂 `GameManager` / `AudioManager` / `ProgressManager` / `UIManager`，进入关卡场景时检测已存在则不再重复创建。
- `EventCenter` 是静态类，**不需要**挂到 `Bootstrap` 上。
