# 配置与存档规范

> 关卡进度与设置项**统一存入 JSON**（不用 PlayerPrefs），由 `ProgressManager` 全权读写。见 [[架构总览]]。

## 1. 存储位置与分工

| 数据 | 载体 | 位置 | 说明 |
|---|---|---|---|
| 关卡解锁进度 | JSON | `Application.persistentDataPath + "/config.json"` | 可写、跨会话持久 |
| 设置项（音量/BGM） | JSON（同文件） | 同上 | 统一由 ProgressManager 管理 |
| BGM 列表 | 常量数组 | `AudioManager` 内 | 切换用 |

- **不用 PlayerPrefs**：关卡进度与设置**统一存入同一个 JSON**，由 `ProgressManager` 全权读写。
- `ProgressManager` 对外暴露：`Load()`、`IsLevelUnlocked(int)`、`UnlockLevel(int)`、`TotalLevels`、`MusicVolume`、`SFXVolume`、`BgmIndex` 等。
- JSON 文件名与内容**已约定**：`config.json`（见第 2 节）。

## 2. JSON 结构（config.json，最终约定）

```json
{
  "totalLevels": 3,
  "unlockedLevels": [1],
  "musicVolume": 0.8,
  "sfxVolume": 0.8,
  "bgmIndex": 0
}
```

- **文件名**：`config.json`，路径 `Application.persistentDataPath + "/config.json"`。
- 字段说明：
  - `totalLevels`：关卡总数，设定为 **3**（`Level_01` ~ `Level_03`）。
  - `unlockedLevels`：已解锁关卡编号（从 1 开始）；**首次默认 `[1]`**，通关后追加。
  - `musicVolume` / `sfxVolume`：音量 0~1，默认 `0.8`。
  - `bgmIndex`：背景音乐序号（`bgmList` 下标），默认 `0`。

### 2.1 数据类 + 读写（JsonUtility）

```csharp
using System;
using System.IO;

[Serializable]
public class ProgressData {
    public int totalLevels;
    public int[] unlockedLevels;
    public float musicVolume;
    public float sfxVolume;
    public int bgmIndex;
}

// 读
ProgressData data = JsonUtility.FromJson<ProgressData>(File.ReadAllText(path));
// 写
File.WriteAllText(path, JsonUtility.ToJson(data, true));
```

- 路径：`Application.persistentDataPath + "/config.json"`。
- JsonUtility 注意点：类须加 `[Serializable]`；不支持 `Dictionary` 与顶层数组；字段名须与 JSON 键一致。

### 2.2 ProgressManager 全权接管

- **原则**：项目内所有 JSON 读写**只允许在 `ProgressManager` 里发生**，对外**只暴露 public 方法**；其他组件（GameManager、UI 等）读写存档**必须经由 `ProgressManager`**，禁止直接碰 `File` / `JsonUtility`。
- 对外 public API：
  - `void Load()`：启动 / 进主菜单时读 JSON。
  - `bool IsLevelUnlocked(int level)`：某关是否解锁。
  - `void UnlockLevel(int level)`：解锁某关（内部自动 `Save()`）。
  - `int TotalLevels`：关卡总数（读自 JSON）。
  - `float MusicVolume` / `float SFXVolume` / `int BgmIndex`：设置项读写属性（setter 内部自动 `Save()`）。
  - `Save()`：**private**，由公开方法在改动后自动调用，外部不直接调。

> 好处：JSON 路径、格式、异常处理只收敛在一处；其他成员无需关心文件细节，只调方法。

### 2.3 读写时机与首次运行

- **读取**：游戏启动 / 进入主菜单时 `ProgressManager.Load()`。
- **写入**：通关时 `ProgressManager.UnlockLevel(当前关 + 1)`（内部自动 `Save()`）。
- **首次运行**：文件不存在 → 创建默认（`unlockedLevels = [1]`，只解锁第 1 关）。

## 3. 设置项（存入 JSON，由 ProgressManager 管理）

| 字段 | 类型 | 默认 | 用途 |
|---|---|---|---|
| `musicVolume` | float | 0.8 | 背景音乐音量 |
| `sfxVolume` | float | 0.8 | 音效音量 |
| `bgmIndex` | int | 0 | 当前背景音乐序号 |

- `ProgressManager` 暴露 `MusicVolume` / `SFXVolume` / `BgmIndex` 属性（内部读写 JSON）。
- `AudioManager` 通过 `ProgressManager` 读取并应用到 `AudioSource.volume` / 切换 BGM。

### 3.1 音量滑动条写盘约定（如有）

- 拖动滑动条时**只改内存变量**（实时预览音量），**不要**每帧写盘。
- **松手时**（`Slider.onEndEdit` 或 `OnPointerUp`）再调用 `ProgressManager`（`MusicVolume = value`，内部自动 `Save()`）。
- 原因：避免拖动过程中频繁写文件造成卡顿。

## 4. BGM 列表与切换

- `AudioManager` 持有 `AudioClip[] bgmList`（Inspector 拖入 `Audio/BGM/` 下的剪辑）。
- `BgmIndex` 作为 `bgmList` 下标（越界要 clamp / 取模保护）。

### 4.1 切换 BGM 完整流程（设置页，立即试听）

1. 用户在设置页选择某首 BGM。
2. UI 调 `ProgressManager.BgmIndex = n`（写盘）。
3. UI 调 `AudioManager.PlayBGM(n)`（**立即试听**）。
4. 下次进游戏：`AudioManager` 从 `ProgressManager.BgmIndex` 读值并播放。

### 4.2 播放接口（精简）

- `PlayBGM(int index)`：切换并播放背景音乐。
- `SetMusicVolume(float v)` / `SetSFXVolume(float v)`：调音量（内部 `AudioSource.volume`）。
- `PlaySFX(AudioClip clip)`：播一次性音效（尖刺死亡、子弹发射等）。
